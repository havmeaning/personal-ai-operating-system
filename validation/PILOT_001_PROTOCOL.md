# Pilot 001 Protocol

## Objective

Run a controlled external pilot to test whether a non-founder operator can use a bounded P.Ai.O.S. workflow to produce a measurable, reviewable result.

## Validation Status

Founder use: extensively documented

External transfer: not yet established

Commercial validation: not established

Enterprise validation: not established

Current stage: controlled external pilot

## Participant Criteria

- Has a real knowledge-work or operating problem.
- Can define a bounded time window.
- Can share public-safe outputs or a redacted case study.
- Agrees to log founder touchpoints and interventions.

## Pilot Flow

1. Complete baseline form.
2. Define mission brief.
3. Capture source inputs.
4. Run the operating loop.
5. Log interventions and founder touchpoints.
6. Capture outcome.
7. Produce case-study draft.
8. Review claims and limitations.

## Success Criteria

Pilot 001 succeeds if it produces a completed case study with:

- baseline
- intervention log
- output artifact
- outcome statement
- limitation statement
- founder-touchpoint count

Success does not require a positive outcome. A failed transfer with honest reporting is still useful evidence.
