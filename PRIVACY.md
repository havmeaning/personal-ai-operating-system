# Privacy

This repository uses public-safe summaries and proof artifacts. It should not publish protected source material merely to prove that records exist.

## Evidence Access Levels

| Level | Meaning |
|---|---|
| Public evidence | Safe for public repository use. |
| Public-safe derivative | Summary or redacted artifact that preserves the claim without exposing protected source detail. |
| Controlled evidence | Can support claims internally but requires review before sharing. |
| Internal operations | Working material not intended for public release. |
| Protected material | Material that should not be published in this repository. |

## Redaction Rules

- Remove direct identifiers.
- Remove private links and internal record references.
- Generalize protected personal details unless they are essential to a public claim.
- Prefer summaries over raw source exports.
- Keep participant data private unless explicit public consent and review exist.

## Never Publish By Default

- raw conversation exports
- unredacted operational archives
- private administrative records
- raw analytics exports containing personal identifiers
- participant data from future pilots
- protected source documents used only to verify public claims

## Review Rule

Before adding a source-derived artifact, update or check:

- `evidence/PUBLIC_CLAIMS_REGISTER.csv`
- `evidence/EVIDENCE_LEDGER.md`
- `evidence/SOURCE_MANIFEST.csv`
- `reports/REPORT_INDEX.md` when applicable
