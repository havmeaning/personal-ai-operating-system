# Versioning

P.Ai.O.S. repository artifacts should use explicit versioning when they make public claims or summarize evidence.

## Report Versions

Reports should include:

- title
- version
- date
- evidence grades
- status
- superseded version, when applicable

## Claim Versions

Claims are tracked by stable IDs in:

- `evidence/PUBLIC_CLAIMS_REGISTER.csv`

If claim wording changes materially, update the register and review date.

## Public-Safe Derivatives

Summaries derived from private source material should state that they are public-safe derivatives and should not imply that the full source is public.
