# P.Ai.O.S. Roadmap

## Current Milestone

Ready for controlled external pilot.

## Near-Term Priorities

1. Complete public documentation governance without exposing protected material.
2. Prepare a pilot kit with baseline measures, success criteria, and intervention logging.
3. Run one controlled external-use case with limited founder involvement.
4. Convert the pilot into a public case-study shell with evidence labels and limitations.
5. Reconcile license scope for software, written methodology, research texts, and conceptual frameworks.

## Validation Boundary

The next milestone is not a broad market claim. It is a controlled transfer test that can honestly report what happened, what did not transfer, and what needs redesign.
