# Operating Loop

The P.Ai.O.S. loop is:

Capture -> Structure -> Analyze -> Decide -> Execute -> Report -> Extract Doctrine

## 1. Capture

Collect raw inputs without pretending they are already clean. Inputs may include notes, exports, dashboards, conversations, observations, documents, decisions, and constraints.

Output: raw evidence packet.

## 2. Structure

Turn raw material into records, claims, constraints, questions, options, owners, dates, and evidence grades.

Output: structured working record.

## 3. Analyze

Identify patterns, gaps, risks, tradeoffs, bottlenecks, and decision points.

Output: analysis note.

## 4. Decide

Select a next action, define success criteria, and record what remains uncertain.

Output: decision log.

## 5. Execute

Carry out the selected action with enough logging to make later review possible.

Output: action record.

## 6. Report

Summarize what happened, what changed, what failed, what was learned, and what evidence supports the account.

Output: after-action report.

## 7. Extract Doctrine

Convert the operation into a reusable rule, template, checklist, or operating principle.

Output: doctrine note or reusable asset.

## Minimal Test

If an artifact cannot show the movement from raw input to decision to report to reusable lesson, it is probably documentation, not yet P.Ai.O.S. evidence.
