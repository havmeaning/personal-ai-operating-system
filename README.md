## Evidence Discipline

Evidence labels used in this repository:

- [V] verified in archive or native export
- [R] user-reported
- [AI] AI interpretation
- [P] proposed
- [S] superseded
- [V-OCR] read from native dashboard screenshots and requiring live confirmation before external use

AI ratings, summaries, and praise are not independent validation. They may help interpret records, but they do not establish transferability, causality, enterprise readiness, or commercial validation.

## Public-Safety Boundary

This public repository should not include protected personal material, direct identifiers, private links, or internal record details unless they are explicitly redacted and necessary for a public evidence claim. Protected source archives are treated as private evidence bases, not public documentation by default.
