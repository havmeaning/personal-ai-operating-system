# Contributing

This repository is a proof system. Contributions should improve clarity, evidence discipline, validation design, templates, or documentation quality.

## Before Opening A Pull Request

- Keep claims specific and evidence-graded.
- Do not add protected source material.
- Update the claims register when public claims change.
- Update the evidence ledger when new evidence artifacts are added.
- Add limitations next to claims.
- Prefer small, reviewable changes.

## Useful Contribution Types

- documentation fixes
- template improvements
- evidence challenges
- validation-protocol improvements
- worked examples using public-safe material
- link and metadata fixes

## Evidence Challenges

If a claim appears unsupported, open an evidence challenge issue and identify:

- exact claim
- file and section
- concern
- suggested evidence grade or wording change
